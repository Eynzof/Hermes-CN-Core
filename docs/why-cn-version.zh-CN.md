# 为什么选择 Hermes CN 版?

Hermes CN 是官方 Hermes Agent(NousResearch/hermes-agent)的持续同步分支。我们在完整跟进上游功能的同时,针对中国大陆网络环境、Windows 平台体验和长期运行的稳定性,做了 40 余项深度优化与修复。对普通用户而言,差异可以概括为一句话:**官方版能用,CN 版在你的网络和你的电脑上真正好用。**

## 一、为中国网络环境而生

- **国内模型服务商一等公民**:火山方舟、百度千帆、腾讯混元、硅基流动、ModelScope、LongCat 等国内平台的密钥与参数直接在设置面板中配置,开箱即用;同时兼容 Anthropic 协议的 Claude 中转站和 MiniMax `/anthropic` 端点,连接测试不再误报"密钥无效"。
- **模型元数据离线优先**:官方版每次保存/切换模型都要联网拉取 models.dev,国内网络下动辄卡住十几秒;CN 版内置快照、异步预热、失败自动降级,模型操作秒开。
- **剔除不可达的隐式探测**:官方版的辅助模型(压缩、起名、视觉)会隐式回退去探测 OpenRouter 等国内无法访问的服务,每次调用白白等待超时;CN 版改为直接回退到可达的供应商,失败也快。
- **安装与更新支持国内镜像**:ripgrep、rtk 等内置工具的下载支持中国镜像回退,告别 GitHub 直连超时。

## 二、Windows 原生体验(官方版的短板)

官方版在 Windows 上强依赖 Git Bash,路径翻译开销大、坑多。CN 版全面转向系统自带的 PowerShell:

- **零安装、开箱即用**:优先使用 PowerShell 7,自动回退到每台 Windows 10/11 都自带的 PowerShell 5.1;同时保留 Git Bash 作为可选项,互不干扰。
- **修复了一整类静默故障**:官方版在纯 PowerShell 环境下,文件读取直接不可用、文件写入会"报告成功但什么都没写进磁盘"(静默丢数据)、搜索功能报错、GBK 中文文件读写乱码并在回写时造成二次损坏——CN 版将文件读写与搜索改为进程内实现,并增加写后逐字节校验,从根上杜绝这类问题。
- **会话内新装的工具立即可用**:每次执行命令前自动从注册表刷新 PATH(带签名缓存,几乎零开销),不再需要重启进程。

## 三、显著的性能提升

针对"第一次操作像卡死"的冷启动问题做了系统性优化:

- 首次工具调用从约 **4.5 秒降到毫秒级**(后台预热 + schema 预序列化缓存);
- 冷启动整体大幅加快:模块导入加速、字节码预编译、消除多余的 WMI 系统查询、SSL 证书校验结果记忆化;
- 终端命令执行可选 PowerShell 会话复用,热命令从约 100ms 降到 1–5ms;
- 桌面端"模型页""健康检查"等接口改为并发 + 缓存 + 异步,打开页面和切换窗口焦点不再卡几秒,也不再阻塞聊天。

## 四、长会话稳定性:修好了官方版"挂着不动"的老大难

- **流式连接假死检测**:官方版在供应商连接半开时会出现"计时器一直走、任务早已死透、永不报错"的永久挂起;CN 版修复检测器打错对象、计时器自我重置死循环、状态不实时上报三个缺陷,卡死必在有限时间内报错并自动重连。
- **定时任务不再静默罢工**:修复官方版 cron 的四类静默失效(守护线程无声死亡、崩溃残留僵尸锁导致永不触发、任务文件损坏无人察觉、时区不一致导致计划漂移),任务哑火会留下明确日志并自动恢复。
- **更抗"模型犯迷糊"**:LLM 写错工具参数名(如 `file` 写成 `path`)时自动纠错;跨轮重复同一工具调用的死循环会被检测并逐级提醒打断;空 API Key 给出清晰的中文可读报错而非底层 SDK 堆栈。
- **严格网关兼容**:自动过滤历史中的空消息,兼容 MiMo 等严格校验的 OpenAI 兼容网关,长会话不再突然 400。
- **桌面体验修复**:任务执行中发送的"引导"消息不再被静默丢弃;连续工具调用不再把界面卡死在"正在运行终端命令"。

## 五、更省 Token,也就更省钱

终端输出经过全新后处理管道:自动去重重复行、按行折叠超长输出、超大输出导出到文件只留摘要;并集成 rtk 工具,对 `git log`、`cargo test`、`npm install` 这类高输出命令自动压缩。模型不再为几千行重复输出付费。

## 六、桌面端开箱即用

CN 桌面运行时一次打包齐所有能力:MCP 客户端、飞书/钉钉/企业微信/个人微信适配器、Node.js 与预构建 TUI——官方版的冻结运行时里这些 SDK 缺失,功能会"静默降级不可用"。此外,第三方库缓存(HuggingFace、tiktoken、Playwright 等)全部收敛到安装盘,装在 D 盘就不会再偷偷塞满 C 盘;网关事件流还新增了 Claude Code / Codex 子代理委托的结构化事件,桌面端可以实时看到"子代理正在干什么"。

## 我们的承诺

CN 版不是"改完就跑"的分叉:我们持续与上游双向同步——上游的每个新版本都会合入,我们的通用性修复(PowerShell 迁移、假死检测、cron 修复等)也在陆续回馈官方仓库。选择 CN 版,得到的是上游全部能力,加上为中国用户打磨过的网络、平台与稳定性体验。
