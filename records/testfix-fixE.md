## Per-file results

- `tests/cli/test_bang_shell_mode.py` -> FIXED (3 tests). `run_bang_command` uses `subprocess.Popen(shell=True)` = cmd.exe on Windows; the upstream POSIX-semantics tests cannot behave the same there: (1) `echo a; echo b` — cmd has no `;` separator, (2) `echo x >&2` — cmd `>&2` semantics differ, (3) `pwd` resolves to Git for Windows' `pwd.exe` which prints msys paths (`/c/Users/...` -> `os.path.realpath` -> `C:\c\Users\...`, msys path doubling). Added `@pytest.mark.skipif(sys.platform == "win32", ...)` to the 3 tests (+`import sys`). Result: 47 passed, 3 skipped.
- `tests/computer_use/test_cua_wsl_manifest_path.py` -> FIXED (production). `tools/computer_use/cua_backend.py::_wsl_windows_path_to_posix` built the DrvFS path with `os.path.join("/mnt", drive, ...)` which uses `\` on Windows, producing `/mnt\c\Users\...`. WSL paths must always use `/` regardless of host. Now builds with explicit forward slashes. Test unchanged. Result: 2 passed.
- `tests/plugins/platforms/photon/test_runtime_record.py` -> FIXED (production). `plugins/platforms/photon/adapter.py` calls `json.dump`/`json.loads` (stdlib semantics) but the merge replaced `import json` with `import orjson` (known class 1); added top-level `import json` (orjson kept for the ndjson parse path). Result: 5 passed, 1 skipped.
