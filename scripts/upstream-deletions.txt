# Paths this fork deliberately deleted from upstream NousResearch/hermes-agent.
#
# `scripts/git_merge.py` reads this file and SKIPS every path that matches, even
# when upstream has a newer version of it or adds a new file under a deleted
# tree: the deletion is a fork decision, not a merge accident, so a sync must
# never resurrect it. The script also treats any path that is missing from the
# working tree as deleted, so this file is the *declaration*; the auto-detection
# is the safety net.
#
# Syntax: one glob per line, POSIX separators, matched against the repo-relative
# path. `**` spans directories, `*` and `?` do not. `#` starts a comment, a
# blank line is ignored, and a leading `!` re-includes a path a broader glob
# above matched. Everything outside this fork's own additions belongs here only
# when the upstream file itself is documentation or generated metadata — never
# for code the fork still ships.
#
# Why these trees are gone: the fork ships the agent, the gateway, the TUI, the
# dashboard, the plugins/skills data and the tests. It does not ship the
# published documentation site, the translated guides, the contributor
# attribution data or the recorded performance reports.
